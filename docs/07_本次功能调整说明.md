# 07 本次功能调整说明

本次版本围绕“家有良田”乡村县城农产品展示网站做了以下调整。

## 1. 前台导航调整

一级菜单保持：

- 首页
- 源头好物
- 时令推荐
- 乡村故事
- 联系农户

“源头好物”已支持鼠标悬停二级菜单：

- 新鲜果蔬：当季蔬菜、水果，现摘现发
- 禽蛋肉奶：土鸡、土鸡蛋、冷鲜肉、羊奶等
- 粮油杂粮：生态大米、菜籽油、绿豆、小米等
- 特产农产品：手工辣酱、红薯粉、腌菜等
- 其他商品：不好归类的散养产品，或农户手作

## 2. 乡村故事独立展示

数据库新增 `article_type` 字段：

- `product`：农产品商品，只在“源头好物 / 时令推荐”展示
- `story`：乡村故事文章，只在“乡村故事”展示

点击“乡村故事”时，不再展示上方商品列表。

## 3. 本地图片路径

图片统一放在：

```text
frontend/public/asset/images
```

数据库保存相对路径，例如：

```text
/asset/images/product-goji.svg
/asset/images/story-harvest.svg
```

Vite 会把 `public` 目录作为站点根目录发布，因此页面可以直接访问 `/asset/images/xxx.svg`。

## 4. 后台内容管理支持插入图片

后台“内容管理”支持两种内容：

- 农产品商品
- 乡村故事文章

编辑正文时，可以选择图片并点击“插入图片到正文”，系统会向 Markdown 内容中追加：

```markdown
![图片说明](/asset/images/product-goji.svg)
```

## 5. 默认账号

管理员：

```text

```

普通管理用户：

```text

story01 / story123
```
