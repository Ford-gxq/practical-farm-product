# 01 项目学习路线

## 项目定位

这个项目不是“大而全”的脚手架，而是适合后端程序员快速实战的前后端分离项目。核心目标是：你能够独立完成一个文章发布网站，并且在面试中讲清楚每一层为什么这样设计。

## 8~12 小时学习安排

### 第 1 小时：跑通项目

1. 执行 `sql/init.sql`
2. 修改 `backend/src/main/resources/application.yml` 的数据库密码
3. 启动后端：`mvn spring-boot:run`
4. 启动前端：`npm install && npm run dev`
5. 访问前台和后台

### 第 2~3 小时：理解后端分层

重点看这些包：

- `controller`：接收 HTTP 请求，做参数校验，返回统一结果
- `service`：写业务逻辑，例如登录、保存文章、删除分类
- `mapper`：数据库访问接口
- `resources/mapper/*.xml`：真正的 SQL
- `exception`：统一异常处理
- `config`：跨域、拦截器、配置读取

### 第 4~5 小时：理解 MyBatis

重点掌握：

- `@Mapper` 的作用
- XML 中 namespace 和 Java Mapper 接口的对应关系
- `resultType` 如何映射实体类
- `<if>` 动态 SQL
- `LIMIT #{pageSize} OFFSET #{offset}` 分页
- `useGeneratedKeys="true" keyProperty="id"` 获取自增 ID

### 第 6~7 小时：理解 Vue3 前端

重点看：

- `src/main.js`：Vue 应用入口
- `src/router/index.js`：前台和后台路由配置
- `src/api/request.js`：Axios 封装、token 请求头、统一错误处理
- `src/store/user.js`：Pinia 存储登录信息
- `views/site`：前台页面
- `views/admin`：后台页面

### 第 8~12 小时：自己改造功能

建议你按顺序完成：

1. 给文章增加“作者”字段
2. 给文章增加“标签”字段
3. 增加评论表和评论接口
4. 增加文章按浏览量排序
5. 把登录 token 改成 JWT
6. 把正文改成 Markdown 编辑器
7. 给后台增加上传封面图功能

## 面试中可以怎么介绍这个项目

这是一个基于 Spring Boot 3 + MyBatis + MySQL + Vue 3 的前后端分离文章发布系统。后端采用 Controller、Service、Mapper 三层架构，使用 MyBatis XML 管理 SQL，提供统一响应、统一异常处理、登录拦截和跨域配置。前端使用 Vue 3、Vue Router、Pinia、Axios 和 Element Plus，实现前台文章浏览和后台文章分类管理。
