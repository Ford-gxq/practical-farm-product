# 03 运行和排错

## 1. MySQL 连接失败

检查 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/practical_blog?...
    username: root
    password: root
```

如果你的 root 密码不是 root，改成自己的密码。

## 2. JDK 版本问题

本项目建议使用 JDK 21。你本地有 JDK8/JDK11/JDK21，启动前建议确认：

```bash
java -version
mvn -version
```

如果 Maven 显示的 Java 不是 21，需要检查 `JAVA_HOME`。

## 3. 前端 npm install 慢

可以配置国内镜像：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

## 4. 前端访问接口失败

确认后端已经启动：

```text
http://localhost:8080/api/site/articles
```

如果浏览器能看到 JSON，说明后端没问题。

## 5. 后台提示登录失效

后台接口需要请求头 `X-Token`。前端已经在 `src/api/request.js` 自动处理。若你手动用 Postman 调试，需要自己带上这个请求头。

## 6. 想导入 IDEA

1. IDEA 打开 `backend` 目录
2. 等 Maven 自动下载依赖
3. 修改 application.yml 数据库密码
4. 运行 `BlogApplication`

## 7. 想导入 VS Code

1. VS Code 打开 `frontend` 目录
2. 安装 Vue 官方插件
3. 执行 `npm install`
4. 执行 `npm run dev`
