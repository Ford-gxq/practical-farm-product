# 05 项目设计说明

## 1. 业务模型

本项目模拟一个简单的内容发布系统：

- 前台用户可以查看已发布文章
- 管理员可以登录后台
- 管理员可以维护分类
- 管理员可以新增、修改、删除文章
- 文章可以是草稿或发布状态

## 2. 表设计

### sys_user

管理员用户表。真实项目可能需要角色、权限、菜单等表。本项目为了降低学习成本，只保留管理员登录。

### blog_category

文章分类表。使用 `deleted` 字段做软删除，避免真实删除数据。

### blog_article

文章表。核心字段包括：

- `category_id`：所属分类
- `title`：标题
- `summary`：摘要
- `content`：正文
- `status`：草稿/发布
- `view_count`：浏览量
- `published_at`：发布时间

## 3. 后端分层

```text
Controller：处理 HTTP 请求和响应
Service：处理业务逻辑
Mapper：定义数据库操作接口
XML：编写 SQL
Entity：数据库表映射对象
DTO：前端请求参数对象
```

## 4. 前端分层

```text
api：接口请求封装
router：路由配置
store：登录状态管理
views/site：前台页面
views/admin：后台页面
```

## 5. 为什么适合面试准备

这个项目覆盖了企业开发中常见的最小闭环：

- 数据库建模
- REST API
- 参数校验
- 登录认证
- 统一异常处理
- MyBatis 动态 SQL
- Vue 后台表格和表单
- 前后端联调

虽然项目体量不大，但每个模块都是真实项目常见模块。
