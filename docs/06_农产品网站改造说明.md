# 农产品展示网站改造说明

## 1. 改造目标

本项目已从“文章发布网站”改造为“县城乡村农产品展示网站”。前台用于展示农户商品，后台用于发布和维护商品信息。

## 2. 导航设计

一级导航：

```text
首页 | 源头好物 | 时令推荐 | 乡村故事 | 联系农户
```

源头好物二级分类：

```text
新鲜果蔬
禽蛋肉奶
粮油杂粮
特产农产品
其他商品
```

## 3. 数据库字段变化

`blog_article` 在原有文章字段基础上新增了商品字段：

| 字段 | 说明 |
|---|---|
| price | 商品价格 |
| unit | 单位，例如 元/斤、元/瓶、元/箱 |
| sales_text | 成交量或热度文案 |
| product_tags | 商品标签，多个用英文逗号分隔 |
| farmer_name | 农户名称 |
| farmer_phone | 农户联系电话 |
| origin_place | 商品产地 |
| recommended | 是否时令推荐，0否，1是 |

## 4. 后端修改点

- `Article.java`：增加商品字段。
- `ArticleSaveRequest.java`：增加商品保存参数。
- `ArticleServiceImpl.java`：保存商品字段。
- `ArticleMapper.xml`：查询、插入、修改 SQL 增加商品字段。
- `sql/init.sql`：初始化农产品分类和测试商品。

## 5. 前端修改点

- `SiteHome.vue`：改成农产品首页，包含导航、二级菜单、商品卡片、乡村故事、联系农户。
- `ArticleDetail.vue`：改成商品详情页，支持价格、农户、电话、产地和 Markdown 渲染。
- `AdminArticles.vue`：改成商品管理，支持价格、单位、标签、农户、电话、产地、推荐等字段。
- `AdminLayout.vue`：后台菜单改成农品后台、商品管理、商品分类。
- `AdminLogin.vue`：保留粒子背景，用户名默认 admin，密码不默认填充。
