# 04 二次开发任务清单

完成以下任务后，你对 Spring Boot 3 + Vue 3 前后端分离项目会更熟练。

## 基础任务

- [ ] 文章增加 author 字段
- [ ] 文章增加 tags 字段
- [ ] 分类删除前检查分类下是否存在文章
- [ ] 文章列表支持按发布时间排序
- [ ] 后台文章列表增加状态筛选

## 进阶任务

- [ ] 登录 token 改成 JWT
- [ ] 密码加密改成 BCrypt
- [ ] 增加用户管理模块
- [ ] 增加评论模块
- [ ] 增加文件上传接口
- [ ] 增加 Markdown 编辑器
- [ ] 增加 Redis 缓存文章详情

## 面试讲解重点

1. 为什么要统一响应体？
2. 为什么要统一异常处理？
3. Controller、Service、Mapper 各自负责什么？
4. MyBatis XML 和注解 SQL 各有什么优缺点？
5. 前端为什么要封装 Axios？
6. Vue Router 路由守卫解决了什么问题？
7. Token 登录和 Session 登录有什么区别？
