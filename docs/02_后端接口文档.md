# 02 后端接口文档

后端基础地址：`http://localhost:8080`

统一响应格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

## 一、前台接口

### 1. 查询分类

`GET /api/site/categories`

### 2. 查询文章列表

`GET /api/site/articles?pageNo=1&pageSize=10&categoryId=1`

### 3. 查询文章详情

`GET /api/site/articles/{id}`

## 二、后台登录

### 1. 登录

`POST /api/admin/auth/login`

请求体：

```json
{
  "username": "admin",
  "password": "admin123"
}
```

返回：

```json
{
  "token": "BLOG_TOKEN_xxx",
  "nickname": "系统管理员"
}
```

后续后台接口请求头都需要：

```text
X-Token: BLOG_TOKEN_xxx
```

## 三、后台分类管理

### 查询分类

`GET /api/admin/categories`

### 新增分类

`POST /api/admin/categories`

```json
{
  "name": "Java 后端",
  "sortOrder": 1
}
```

### 修改分类

`POST /api/admin/categories`

```json
{
  "id": 1,
  "name": "Java 后端进阶",
  "sortOrder": 1
}
```

### 删除分类

`DELETE /api/admin/categories/{id}`

## 四、后台文章管理

### 分页查询文章

`GET /api/admin/articles?pageNo=1&pageSize=10&keyword=Spring`

### 查询文章详情

`GET /api/admin/articles/{id}`

### 新增文章

`POST /api/admin/articles`

```json
{
  "categoryId": 1,
  "title": "Spring Boot 3 实战",
  "summary": "文章摘要",
  "coverImage": "",
  "content": "文章正文",
  "status": 1
}
```

### 修改文章

`POST /api/admin/articles`

```json
{
  "id": 1,
  "categoryId": 1,
  "title": "Spring Boot 3 实战修改版",
  "summary": "文章摘要",
  "coverImage": "",
  "content": "文章正文",
  "status": 1
}
```

### 删除文章

`DELETE /api/admin/articles/{id}`
